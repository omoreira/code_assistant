================================================================================
                            SYSTEM ARCHITECTURE
================================================================================

WORKFLOW PIPELINE:
──────────────────

  User Input
      ↓
  starterfile_creator.py  [DEFINE PROJECT]
      ↓
  starterfile.pseudo  [SPECIFICATION FILE]
      ↓
  blueprint_renderer.py  [CREATE SKELETON]
      ↓
  Directory Structure + Empty Files  [SCAFFOLD]
      ↓
  pseudocode_renderer.py  [GENERATE CODE]
      ↓
  Real Working Code  [FINISHED PRODUCT]


THREE MODES OF OPERATION:
─────────────────────────

MODE 1: CREATE SPECIFICATION
  Tool: starterfile_creator.py
  Input: User interaction
  Output: starterfile.pseudo
  
MODE 2: CREATE SKELETON
  Tool: blueprint_renderer.py
  Input: starterfile.pseudo (REPOMAP section)
  Output: Directory tree + empty files
  
MODE 3A: GENERATE CODE (Fresh Project)
  Tool: pseudocode_renderer.py
  Input: starterfile.pseudo (PSEUDOCODE section)
  Output: Real code files
  Cleanup: Deletes starterfile.pseudo
  
MODE 3B: GENERATE CODE (Enhance Existing)
  Tool: pseudocode_renderer.py
  Input: Inline pseudocode comments
  Output: Real code files
  No cleanup needed
