# data/ — reserved for a future iteration

This directory is intentionally **empty and reserved**. No current code reads or
writes it.

It is the designated home for a later (posterior) subsystem: an
**epistemic-rigor** layer built on **graph-based memory retrieval** and a
**DPO (Direct Preference Optimization)** preference system. Those components
will persist their databases here in a future iteration.

Until then:

- do not store databases or other artifacts here, and
- do not remove the directory — keeping it reserved (and empty) preserves the
  intended layout.
